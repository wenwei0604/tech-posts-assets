# tech-posts-assets

技術文章用的圖片（公開）。**只放已遮蔽、可公開的圖**，原圖永遠不進這個 repo。

路徑規則：`<文章代號>/<序號>-<說明>.png`，例如 `C4/03-argocd-sync.png`。


代號可用 `A`–`H` 加數字（如 `C1`、`G13`、`H2`），或 `M` 加數字與可選的小寫尾碼（如 `M1a`、`M1b`）。序號固定兩位，說明僅小寫英數與連字號；副檔名可用 `png`、`svg`、`jpg`、`webp`，封面使用 `00-cover.png`。CI 只檢查路徑，內容仍須逐張人工審核。

可公開 SVG 只能含基本幾何與已審核文字，不帶 script、外部引用、隱藏圖層、內嵌原圖或編輯器中繼資料。原始截圖與可還原的遮蔽專案不可加入本 repo。

## 範例

- [C1/01-draft-check.png](C1/01-draft-check.png)／[SVG](C1/01-draft-check.svg)：單篇稿件檢查流程，通過才存成草稿；未通過則修正後重試。只含通用文字，非實機截圖。
